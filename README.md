# Fine-tune Gemini on Gemini Enterprise Agent Platform

Hands-on codelab for **DevFest KL 2026**, organized by Google Developer Group Kuala Lumpur.

Conducted by **Christine Tee**, Principal Machine Learning Engineer, Turing.

Adapted from the Google Codelab *Fine-tune Gemini on Gemini Enterprise Agent Platform* by Drew Brown, part of the Production-Ready AI with Google Cloud learning path.

## What's inside

A single-page, 12-step codelab: supervised fine-tuning of Gemini 3.5 Flash for article summarization, with baseline and tuned ROUGE evaluation.

- Light and dark mode (follows your system, with a toggle)
- Progress bar and step list
- Copy buttons on every code block
- Screenshots in `img/`

## View it

Open `index.html` in a browser, or enable GitHub Pages on the `main` branch.
